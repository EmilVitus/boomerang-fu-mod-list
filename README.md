# Boomerang Fu-mods til Windows

Et katalog over de offentlige mods til pc-udgaven af *Boomerang Fu* (Steam, Windows). Listen kan filtreres på type og status, og hvert kort har version, installation, kompatibilitet og links.

Kataloget er uafhængigt af Cranky Watermelon og indeholder ingen filer fra spillet.

## Kør det lokalt

Kræver Node.js 22.

```bash
npm install
npm run dev
```

Udviklingsserveren lytter på port 3847. Åbn [http://localhost:3847](http://localhost:3847).

```bash
npm run lint
npm run build
```

## Hvad listen dækker

Kilderne er tjekket 6. november 2026. Spillet var da på version 1.4.0 (3. november 2026). Ingen af modsene er bekræftet på den version.

Data ligger i `data/mods.ts`.
