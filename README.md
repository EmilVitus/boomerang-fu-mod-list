# Boomerang Fu Mods for Windows

A catalog of the public mods for the PC version of *Boomerang Fu* (Steam, Windows). The list can be filtered by type and status, and each card shows version, installation, compatibility and links. The lineage tree shows which mod is built on top of which: the Chaos family, the two online prototypes plus Boomerang Fu Online, and 8 Player Mod, Team Mint, Hat Loader, the speedrun timer and Mod Manager. One table compares the Chaos family's features across Slaughter House, Chaos Mod, the stack fork, Remix and Boomerang Mods. A table below separates extra people, bots and online play.

The catalog is independent of Cranky Watermelon and contains no files from the game.

## Run locally

Requires Node.js 22.

```bash
npm install
npm run dev
```

The development server listens on port 3847. Open [http://localhost:3847](http://localhost:3847).

```bash
npm run lint
npm run build
```

## What the list covers

Sources were checked on 27 November 2026. Each card shows when the mod was last updated publicly. The game is on version 1.4.1 (19 November 2026). 1.4.0 arrived on 3 November 2026. A table above the install notes lists the newest game version each mod's source says it was tried on, and the Steam version that was current when that mod was last updated. Team Mint 1.0.0 is a third-team zip from 26 November 2026. Mod Manager 1.0.0 and Speedrun Timer 1.1.0 were published on 25 November 2026; those release tags have no zip, so the files are in the repos. BepInEx 5.4.23.6, which the 5.x line of mods uses, was released on 24 October 2026.

Data lives in `data/mods.ts`.

# Boomerang Fu-mods til Windows

Et katalog over de offentlige mods til pc-udgaven af *Boomerang Fu* (Steam, Windows). Listen kan filtreres på type og status, og hvert kort har version, installation, kompatibilitet og links. Stamtræet viser, hvilken mod der er bygget oven på hvilken: Chaos-familien, de to online-prototyper plus Boomerang Fu Online, og 8 Player Mod, Team Mint, Hat Loader, speedrun-timeren og Mod Manager. En tabel sammenligner Chaos-familiens funktioner på tværs af Slaughter House, Chaos Mod, stack-forken, Remix og Boomerang Mods. En tabel under den skiller ekstra mennesker, bots og spil over nettet ad. Remix blev opdateret 13. november 2026, og samme dag kom kildepakken Boomerang Mods med Gravity Well. Boomerang Fu Online 2.4.1 er en færdig zip fra 7. november 2026. Speedrun Timer 1.1.0 og Mod Manager 1.0.0 er plugins fra 25. november 2026. Team Mint 1.0.0 er et tredje hold fra 26. november 2026.

Kataloget er uafhængigt af Cranky Watermelon og indeholder ingen filer fra spillet.

## Kør det lokalt

Kræver Node.js 22.

```bash
npm install
npm run dev
```

Udviklingsserveren lytter på port 3847. Åbn [http://localhost:3847](http://localhost:3847).

```bash
npm run lint
npm run build
```

## Hvad listen dækker

Kilderne er tjekket 27. november 2026. Hvert kort viser, hvornår modden sidst blev opdateret offentligt. Spillet er på version 1.4.1 (19. november 2026). 1.4.0 kom 3. november 2026. En tabel over installationsvejledningen viser den nyeste spilversion, som hver mods kilde selv siger, at den er prøvet på, og den Steam-version, der var aktuel, da modden sidst blev opdateret. Team Mint 1.0.0 er en zip med et tredje hold fra 26. november 2026. Mod Manager 1.0.0 og Speedrun Timer 1.1.0 blev lagt op 25. november 2026. De to release-tags har ingen zip, så filerne ligger i repoerne. BepInEx 5.4.23.6, som modsene i 5.x-linjen bruger, blev udgivet 24. oktober 2026.

Data ligger i `data/mods.ts`.
