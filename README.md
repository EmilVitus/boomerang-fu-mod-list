# Boomerang Fu Mods for Windows

A catalog of the public mods for the PC version of *Boomerang Fu* (Steam, Windows). The list can be filtered by type and status, and each card shows version, installation, compatibility and links. The lineage tree shows which mod is built on top of which: the Chaos family, the two online prototypes, and the two mods with their own codebase. One table compares the Chaos family's features across Slaughter House, Chaos Mod, the stack fork, Remix and Boomerang Mods. A table below separates extra people, bots and online play.

The catalog is independent of Cranky Watermelon and contains no files from the game.

## Run locally

Requires Node.js 22.

```bash
npm install
npm run dev
```

The development server listens on port 3847. Open [http://localhost:3847](http://localhost:3847).

```bash
npm run lint
npm run build
```

## What the list covers

Sources were checked on 20 November 2026. Each card shows when the mod was last updated publicly. The game was then on version 1.4.0 (3 November 2026). None of the mods has been confirmed on that version. BepInEx 5.4.23.6, which the 5.x line of mods uses, was released on 24 October 2026.

Data lives in `data/mods.ts`.

# Boomerang Fu-mods til Windows

Et katalog over de offentlige mods til pc-udgaven af *Boomerang Fu* (Steam, Windows). Listen kan filtreres på type og status, og hvert kort har version, installation, kompatibilitet og links. Stamtræet viser, hvilken mod der er bygget oven på hvilken: Chaos-familien, de to online-prototyper, og de to mods med egen kodebase. En tabel sammenligner Chaos-familiens funktioner på tværs af Slaughter House, Chaos Mod, stack-forken, Remix og Boomerang Mods. En tabel under den skiller ekstra mennesker, bots og spil over nettet ad. Remix blev opdateret 13. november 2026, og samme dag kom kildepakken Boomerang Mods med Gravity Well.

Kataloget er uafhængigt af Cranky Watermelon og indeholder ingen filer fra spillet.

## Kør det lokalt

Kræver Node.js 22.

```bash
npm install
npm run dev
```

Udviklingsserveren lytter på port 3847. Åbn [http://localhost:3847](http://localhost:3847).

```bash
npm run lint
npm run build
```

## Hvad listen dækker

Kilderne er tjekket 20. november 2026. Hvert kort viser, hvornår modden sidst blev opdateret offentligt. Spillet var da på version 1.4.0 (3. november 2026). Ingen af modsene er bekræftet på den version. BepInEx 5.4.23.6, som modsene i 5.x-linjen bruger, blev udgivet 24. oktober 2026.

Data ligger i `data/mods.ts`.
